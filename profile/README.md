# Durable IT Solutions

Personal software brand of [Ben de Bruijn](https://github.com/Duracell1989). Cross-platform developer tools and end-user applications, built on modern .NET.

## Products

- **[SevenZipSharper](https://github.com/Dura-IT/sevenzipsharper)** — cross-platform .NET 10 library for reading and writing 7-Zip archives.
- **[avalonia-admob](https://github.com/Dura-IT/avalonia-admob)** — free, open-source AdMob ads for Avalonia UI (banner, native, interstitial, rewarded, and app-open) from one C# codebase across iOS and Android. On [NuGet](https://www.nuget.org/packages/DuraIT.Avalonia.AdMob).
- **Questmark** *(coming soon)* — mobile game-progression tracker for Final Fantasy X and Elden Ring. Coming to the App Store and Google Play.
