# Durable IT Solutions

Personal software brand of [Ben de Bruijn](https://github.com/Duracell1989). Cross-platform developer tools and end-user applications, built on modern .NET.

## Products

- **[SevenZipSharper](https://github.com/Dura-IT/sevenzipsharper)** — cross-platform .NET 10 library for reading and writing 7-Zip archives.
